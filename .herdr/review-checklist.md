# Review checklist of the automatic review (`todo run --auto-review`): one bug class per line, at most 25 lines, each ending with its source in parentheses, a DECISIONS.md section title or a commit sha. Lines starting with # are not given to the model.
- An environment variable (HERDR_WORKSPACE_ID, a pane or socket variable) read without the remote and empty-value guards that an existing helper in the same code already has; reuse the helper. (source: bc6086b79)
- A concrete fact (a host name or IP address, a port, an absolute or personal path) written into code, docs, fixtures or tests instead of being taken from the repository, its configuration or DNS. (source: DECISIONS.md "A moved host: DNS names, a one-off search, no registry")
- An in-memory queue, history, map or cache with no bound or eviction, or a bounded one whose overflow loses entries silently instead of reporting the loss. (source: 65927cef1)
- A timing assumption: an added sleep, wait or longer timeout where the code or test should wait for the observed event, or a flaky test "fixed" by raising its wait instead of its cause. (source: DECISIONS.md "Enforcing the added-delay rule")
- A flaky test fixed by tripling its waits instead of at its asynchronous cause (a dropped click on a redrawing screen, a file read before its writer finished, a reconnect delay). (source: 41d1f907e)
- An endpoint contract change hidden in a regenerated schema or fixture: a changed field, enum variant or parameter of an advertised method or frozen codec, where a new method or codec name was needed and the old shape had to stay. (source: 1092ef17e)
- OS-specific code (cfg(unix), cfg(windows), cfg(target_os), an OS API) outside src/platform/<os>.rs, or Unix-only code that is dead or does not compile on Windows. (source: 2b36cba48)
- A test that asserts one OS's behaviour (a Unix path, a symlink, a Unix permission, a shell command) on every OS instead of gating the test or the helper to that OS. (source: 46e4df2c7)
